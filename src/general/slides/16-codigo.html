DEMONSTRAÇÃO / LÓGICA

Explicite a regra antes de automatizar.

Um exemplo pequeno facilita a discussão sobre critérios e limites.

EXEMPLO.JS

function priorizar(impacto, esforco) {
  if (esforco <= 0) {
    throw new Error("Esforço inválido");
  }
  return impacto / esforco;
}

priorizar(8, 2); // resultado: 4
LEITURA DO EXEMPLO

Validação antes do cálculo.

A regra é simples e permite discutir os dados de entrada, o resultado e os casos inválidos.
