# Retomar uma tarefa

Abra presentation-template/ como raiz. Execute python3 tools/prepare.py nesta primeira rodada.
Se houver pending_visual_approval, aguarde feedback antes de alterar os temas gerais.

Leia AGENTS.md, tools/skills/resume-work/SKILL.md e [PROJETO]/SESSION.json.
Confirme o arquivo-alvo antes de editar. Execute somente a próxima ação registrada,
ou atualize-a se a evidência mostrar que está desatualizada.

Para conteúdo, leia um fragmento por vez. Para falha técnica, leia somente o módulo
afetado. Registre comandos/resultados reais e o próximo passo. Preserve o HTML
final autocontido; fontes externas existem só durante desenvolvimento.
