# Iniciar uma apresentação (copie e preencha)

Esta pasta presentation-template/ é a raiz independente. Execute python3 tools/prepare.py.
Leia AGENTS.md e tools/skills/author-slides/SKILL.md. Crie uma apresentação
do tipo [EXECUTIVA/TÉCNICA/PITCH/AULA/OUTRO] sobre [TEMA], para [PÚBLICO],
com duração [TEMPO], objetivo/decisão [OBJETIVO] e fontes [FONTES].

Primeiro produza brief e storyboard. Se faltar dado essencial, registre a lacuna.
Adapte no máximo três slides por rodada e mantenha SESSION.json atualizado.
O entregável final precisa ser UM HTML autocontido com CSS, PPTX nativo editável,
impressão 16:9, navegação e apresentação embutidos. Use o build existente.
Não reimplemente o runtime nem crie dependências externas para economizar contexto.
Não promova o estilo de previews/ sem aprovação visual explícita.
