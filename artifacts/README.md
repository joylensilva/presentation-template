# Artefatos de teste

Relatórios, PNGs, PDFs e PPTX de teste são gravados aqui pelos comandos padrão.
Não são fontes. `integration-test-only.pptx` tem uma alteração deliberada na capa.
Para obter um PPTX de produção, execute `tools/export_pptx.py` sobre o HTML final.
O entregável principal é sempre um HTML autocontido.

Na distribuição limpa, esta pasta contém apenas este README. Os comandos de
validação recriam suas saídas quando necessário; nenhum arquivo gerado aqui
é necessário para criar, abrir ou exportar apresentações.
